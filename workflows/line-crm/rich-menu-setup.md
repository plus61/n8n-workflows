# LINEリッチメニュー設定ガイド

## 📝 概要

LINEリッチメニューを設定し、ユーザーのタップアクションをNotionに記録するためのガイドです。

## ⚠️ 重要: LINE Webhook URLの制限

LINE公式アカウントでは、**1つのチャネルに対して設定できるWebhook URLは1つのみ**です。

### 推奨される運用方法

**単一Webhookでイベントタイプによる分岐（推奨）**

```
LINE → 単一Webhook URL → n8nワークフロー → イベントタイプで分岐
                                          ├─ follow → リード登録
                                          ├─ message → メッセージ処理
                                          └─ postback → リッチメニュー処理
```

**メリット**:
- ✅ LINE公式仕様に準拠
- ✅ シンプルな構成
- ✅ 管理が容易
- ✅ 追加設定不要

## 🛠️ 設定手順

### ステップ 1: LINE Developers Console設定

#### Webhook URL確認

1. LINE Developers Consoleにアクセス
   ```
   https://developers.line.biz/console/
   ```

2. チャネルを選択

3. Messaging API設定タブを開く

4. Webhook URL確認
   ```
   https://n8n-python-production-344b.up.railway.app/webhook/line-lead-notion
   ```

5. Webhook送信を有効化
   - 「Webhookの利用」を「オン」に設定
   - 「検証」ボタンで接続確認

### ステップ 2: リッチメニュー作成

#### 2-1. リッチメニュー管理画面を開く

1. LINE Official Account Managerにアクセス
   ```
   https://manager.line.biz/
   ```

2. アカウントを選択

3. 左メニューから「リッチメニュー」を選択

4. 「作成」ボタンをクリック

#### 2-2. 基本設定

| 項目 | 設定値 |
|-----|--------|
| タイトル | Main Menu |
| 表示期間 | 常に表示 |
| メニューバーのテキスト | メニュー |
| テンプレート | 大（2分割） |

#### 2-3. コンテンツ設定

**画像アップロード**:
- サイズ: 2500 x 1686 px（推奨）
- 形式: JPG, JPEG, PNG

### ステップ 3: アクション設定

#### 左側エリア（エリアA）

**アクションタイプ**: テキスト

**テキスト**:
```
サービス情報
```

**ラベル**: サービス情報

#### 右側エリア（エリアB）

**アクションタイプ**: テキスト

**テキスト**:
```
お問い合わせ
```

**ラベル**: お問い合わせ

### ステップ 4: リッチメニュー公開

1. 設定内容を確認
2. 「保存」ボタンをクリック
3. 「公開」ボタンをクリック
4. リッチメニューが有効化される

## 🧪 テスト手順

### テスト 1: リッチメニュー表示確認

1. LINEアプリを開く
2. 公式アカウントのトーク画面を開く
3. 画面下部にリッチメニューが表示されることを確認

### テスト 2: メッセージ送信確認

1. リッチメニューの左側（サービス情報）をタップ
2. n8nワークフローの実行履歴を確認
3. 実行履歴に新しいレコードが追加されていることを確認

### テスト 3: Notion更新確認

1. Notionデータベースを開く
2. 自分のユーザーレコードを確認
3. 以下が更新されていることを確認:
   - **Rich Menu ID**: `service_info` または `contact_us`
   - **Last Message Date**: タップ日時
   - **Tags**: `高関心` が追加

## 📊 期待される動作

### ユーザーの行動フロー

```
1. ユーザーがリッチメニューをタップ
   ↓
2. LINEがメッセージイベントを送信
   ↓
3. n8nワークフローが起動
   ↓
4. メッセージを解析
   ↓
5. Notionでユーザーを検索
   ↓
6. Notionレコードを更新
   - Rich Menu ID: タップしたメニューID
   - Last Message Date: タップ日時
   - Tags: 「高関心」を追加
   ↓
7. ログ記録
   ↓
8. LINEに成功レスポンス返却
```

### Notionでの記録内容

| フィールド | 更新内容 | 例 |
|-----------|---------|-----|
| Rich Menu ID | タップしたメニューID | `service_info` |
| Last Message Date | タップ日時 | `2025-10-26 12:00` |
| Tags | 「高関心」タグを追加 | `[高関心]` |

## 🎯 活用シーン

### 1. ユーザーの関心度測定

- リッチメニューをタップ = 高関心ユーザー
- Tagsに「高関心」を自動付与
- 優先的にフォローアップ

### 2. メニュー別の人気度分析

- Rich Menu IDを集計
- どのメニューが人気か分析
- メニュー構成の最適化

### 3. エンゲージメント測定

- Last Message Dateを記録
- アクティブユーザーの特定
- 休眠ユーザーの検出
