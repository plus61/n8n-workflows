# Notionダッシュボードビュー作成ガイド

## 📊 概要

LINE Lead CRMシステムのNotionデータベースに、分析・管理用のビューを作成します。

## 🎯 作成するビュー（7種類）

### 1. 全体ビュー（Overall View）

- **タイプ**: Table
- **目的**: 全リードの一覧表示
- **フィルター**: なし
- **ソート**: Created Date（降順）
- **表示プロパティ**: 全て

### 2. ステップ配信管理ビュー

- **タイプ**: Board
- **目的**: ステップ配信の進捗管理
- **グループ化**: Step Status
- **フィルター**: Step Status ≠ 完了
- **ソート**: Last Message Date（昇順）

### 3. 高関心リードビュー

- **タイプ**: Table
- **目的**: 高関心ユーザーの特定
- **フィルター**: Tags contains 高関心
- **ソート**: Last Message Date（降順）

### 4. フォローアップ必要ビュー

- **タイプ**: Table
- **目的**: フォローアップが必要なリード
- **フィルター**: 
  - Tags contains 要フォロー OR
  - Last Message Date < 7日前
- **ソート**: Last Message Date（昇順）

### 5. アクティブユーザービュー

- **タイプ**: Table
- **目的**: 最近アクティブなユーザー
- **フィルター**: Last Message Date > 7日以内
- **ソート**: Last Message Date（降順）

### 6. 日別登録数ビュー

- **タイプ**: Calendar
- **目的**: 登録日の可視化
- **カレンダー基準**: Created Date

### 7. タグ別分析ビュー

- **タイプ**: Board
- **目的**: タグ別のユーザー管理
- **グループ化**: Tags
- **ソート**: Last Message Date（降順）

## 📝 ビュー作成手順

### ステップ 1: Notionデータベースを開く

1. Notionでデータベースを開く
2. 右上の「+」ボタン（または「Add a view」）をクリック

### ステップ 2: 各ビューを作成

各ビューの詳細な作成手順は上記の仕様に従って設定してください。

#### フィルター設定のポイント

- **Contains**: 特定のタグを含む
- **Is before**: 指定日以前
- **Is after**: 指定日以降
- **Is not**: 特定の値ではない

#### ソート設定のポイント

- **Ascending**: 昇順（古い順）
- **Descending**: 降順（新しい順）

## 🎨 ビューのカスタマイズ

### カラーコーディング

#### Step Statusプロパティ

- `未配信`: グレー
- `配信中`: ブルー
- `完了`: グリーン

#### Tagsプロパティ

- `高関心`: レッド
- `中関心`: イエロー
- `低関心`: グレー
- `要フォロー`: オレンジ

## 📊 ビュー活用方法

### 1. 全体ビュー

- **用途**: データベース全体の概要把握
- **確認頻度**: 毎日
- **アクション**: 新規登録の確認、異常データのチェック

### 2. ステップ配信管理ビュー

- **用途**: ステップ配信の進捗管理
- **確認頻度**: 毎日
- **アクション**: 配信状況の確認、停滞ユーザーの特定

### 3. 高関心リードビュー

- **用途**: 高関心ユーザーへの優先対応
- **確認頻度**: 毎日
- **アクション**: 個別フォローアップ、特別オファーの送信

### 4. フォローアップ必要ビュー

- **用途**: フォローアップが必要なリードの管理
- **確認頻度**: 週1回
- **アクション**: 再エンゲージメント施策の実施

### 5. アクティブユーザービュー

- **用途**: 最近アクティブなユーザーの把握
- **確認頻度**: 毎日
- **アクション**: エンゲージメント維持施策の実施

### 6. 日別登録数ビュー

- **用途**: 登録トレンドの可視化
- **確認頻度**: 週1回
- **アクション**: キャンペーン効果の測定

### 7. タグ別分析ビュー

- **用途**: セグメント別のユーザー管理
- **確認頻度**: 週1回
- **アクション**: セグメント別施策の立案

## 📊 主要KPI

### 1. 登録数

- **計算方法**: 全レコード数
- **目標**: 月間100件以上
- **確認ビュー**: 全体ビュー、日別登録数ビュー

### 2. アクティブ率

- **計算方法**: アクティブユーザー数 / 全ユーザー数
- **目標**: 30%以上
- **確認ビュー**: アクティブユーザービュー

### 3. 高関心率

- **計算方法**: 高関心タグ数 / 全ユーザー数
- **目標**: 20%以上
- **確認ビュー**: 高関心リードビュー

### 4. ステップ完了率

- **計算方法**: ステップ完了数 / 配信開始数
- **目標**: 50%以上
- **確認ビュー**: ステップ配信管理ビュー

### 5. リッチメニュー利用率

- **計算方法**: Rich Menu ID記録数 / 全ユーザー数
- **目標**: 40%以上
- **確認ビュー**: 高関心リードビュー
