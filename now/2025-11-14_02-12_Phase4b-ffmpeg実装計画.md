## 💻 Node 2: Python実装詳細

### 完全なPythonコード

```python
import subprocess
import requests
import os
import time
import base64
import json

# 入力データ取得
input_data = items[0]['json']

# Phase4aから受け取ったメタデータ
section = input_data.get('section', '')
duration = input_data.get('duration', 3)
image_url = input_data.get('image_url', '')
motion_prompt = input_data.get('motion_prompt', '')
text = input_data.get('text', '')
script_id = input_data.get('script_id', '')

# バリデーション
if not image_url:
    raise ValueError(f"画像URLが見つかりません: section={section}")

if not isinstance(duration, (int, float)) or duration <= 0:
    raise ValueError(f"不正なduration値: {duration}, section={section}")

# 一時ファイルパス
timestamp = int(time.time() * 1000)
input_path = f"/tmp/slide_{section}_{timestamp}.png"
output_path = f"/tmp/video_{section}_{timestamp}.mp4"

try:
    # ステップ1: Cloudinaryから画像ダウンロード
    print(f"画像ダウンロード開始: {image_url}")
    response = requests.get(image_url, timeout=30)
    response.raise_for_status()

    with open(input_path, 'wb') as f:
        f.write(response.content)

    file_size = os.path.getsize(input_path)
    print(f"画像ダウンロード完了: {file_size} bytes")

    # ステップ2: ffmpegで動画生成
    ffmpeg_cmd = [
        'ffmpeg',
        '-loop', '1',              # 静止画をループ
        '-i', input_path,          # 入力画像
        '-t', str(duration),       # 動画の長さ（秒）
        '-c:v', 'libx264',         # H.264コーデック
        '-pix_fmt', 'yuv420p',     # 互換性の高いピクセルフォーマット
        '-vf', 'scale=1080:1920',  # 1080x1920（縦動画）
        '-r', '30',                # フレームレート30fps
        '-y',                      # 上書き確認なし
        output_path
    ]

    print(f"ffmpeg実行開始: duration={duration}秒, section={section}")
    result = subprocess.run(
        ffmpeg_cmd,
        capture_output=True,
        text=True,
        check=True,
        timeout=60  # 最大60秒
    )

    # ffmpeg出力をログに記録
    if result.stderr:
        print(f"ffmpeg stderr: {result.stderr[-500:]}")  # 最後の500文字のみ

    # 生成された動画ファイル確認
    if not os.path.exists(output_path):
        raise FileNotFoundError(f"動画ファイルが生成されませんでした: {output_path}")

    video_size = os.path.getsize(output_path)
    print(f"動画生成完了: {video_size} bytes, duration={duration}秒")

    # ステップ3: 動画ファイルをData URIに変換（Cloudinaryアップロード用）
    with open(output_path, 'rb') as f:
        video_data = f.read()

    video_base64 = base64.b64encode(video_data).decode('utf-8')
    video_data_uri = f"data:video/mp4;base64,{video_base64}"

    # Cloudinaryアップロード設定
    cloudinary_config = {
        'cloud_name': 'drzmodro8',
        'upload_preset': 'n8n_meo_wf7_slide',
        'folder': 'n8n_meo_wf7_slide'
    }

    # 出力データ
    output_data = {
        'section': section,
        'duration': duration,
        'motion_prompt': motion_prompt,
        'text': text,
        'script_id': script_id,
        'filename': f'video_{section}.mp4',
        'cloudinary_file': video_data_uri,
        'cloudinary_upload_preset': cloudinary_config['upload_preset'],
        'cloudinary_cloud_name': cloudinary_config['cloud_name'],
        'cloudinary_folder': cloudinary_config['folder'],
        'video_size_bytes': video_size
    }

    print(f"処理完了: section={section}, video_size={video_size} bytes")
    return [{'json': output_data}]

except requests.RequestException as e:
    error_msg = f"画像ダウンロードエラー: {str(e)}, URL={image_url}"
    print(error_msg)
    raise Exception(error_msg)

except subprocess.CalledProcessError as e:
    error_msg = f"ffmpeg実行エラー: {e.stderr[-500:]}, section={section}"
    print(error_msg)
    raise Exception(error_msg)

except subprocess.TimeoutExpired:
    error_msg = f"ffmpegタイムアウト: duration={duration}秒, section={section}"
    print(error_msg)
    raise Exception(error_msg)

except Exception as e:
    error_msg = f"予期しないエラー: {str(e)}, section={section}"
    print(error_msg)
    raise

finally:
    # クリーンアップ: 一時ファイル削除
    try:
        if os.path.exists(input_path):
            os.remove(input_path)
            print(f"一時画像ファイル削除: {input_path}")

        if os.path.exists(output_path):
            os.remove(output_path)
            print(f"一時動画ファイル削除: {output_path}")
    except Exception as cleanup_error:
        print(f"クリーンアップエラー（無視）: {cleanup_error}")
```

### 実装の特徴

**エラーハンドリング**:
- 画像ダウンロード失敗時の詳細エラー
- ffmpeg実行エラー時のstderr出力
- タイムアウト処理（60秒）
- 予期しないエラーのキャッチ

**ログ出力**:
- 各ステップの開始・完了をログ記録
- ファイルサイズの記録
- エラー時の詳細情報

**パフォーマンス**:
- リクエストタイムアウト: 30秒
- ffmpegタイムアウト: 60秒
- 一時ファイルの即座クリーンアップ

**ffmpegパラメータ解説**:
- `-loop 1`: 静止画を連続ループ（動画化）
- `-t {duration}`: 出力動画の長さ（秒単位）
- `-c:v libx264`: H.264コーデック（広い互換性）
- `-pix_fmt yuv420p`: ピクセルフォーマット（ほぼ全プレイヤー対応）
- `-vf scale=1080:1920`: 1080x1920解像度（縦動画）
- `-r 30`: 30fps（滑らか）

## 🔧 トラブルシューティング

### エラー1: `ffmpeg: not found`

**症状**: Pythonコード実行時に`FileNotFoundError: [Errno 2] No such file or directory: 'ffmpeg'`

**原因**: ffmpegがPATHに存在しない

**解決策**:
```python
# フルパス指定
ffmpeg_cmd = [
    '/usr/bin/ffmpeg',  # Alpine: /usr/bin/ffmpeg
    '-loop', '1',
    # ...
]
```

### エラー2: `Cloudinary upload failed: File too large`

**症状**: Node 3でタイムアウトまたはエラー

**原因**: 動画ファイルサイズが大きすぎる（>100MB）

**解決策**:
```python
# ffmpegで圧縮率調整
ffmpeg_cmd = [
    'ffmpeg',
    '-loop', '1',
    '-i', input_path,
    '-t', str(duration),
    '-c:v', 'libx264',
    '-crf', '28',  # 圧縮率（18-28推奨、高いほど小さい）
    '-pix_fmt', 'yuv420p',
    '-vf', 'scale=1080:1920',
    '-r', '30',
    '-y',
    output_path
]
```

### エラー3: `Duration mismatch: expected 3s, got 0.04s`

**症状**: 生成された動画の長さが意図と異なる

**診断**:
```bash
# ffprobeで動画確認
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 /tmp/test.mp4
```

**解決策**: ffmpegコマンドの`-t`パラメータを確認、float型で渡す
