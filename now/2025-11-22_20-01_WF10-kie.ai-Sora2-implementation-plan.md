## 🎯 Phase 1: API認証準備（所要時間: 30分）

### 1.1 kie.ai API Key取得

**手順**:
1. https://kie.ai にアクセス
2. アカウント登録/ログイン
3. Dashboard → API Keys → Create New Key
4. API Keyをコピー (形式: `kie_...`)

**Railway環境変数設定**:
```bash
railway variables set KIE_AI_API_KEY=kie_xxxxxxxxxxxxx --service n8n-python
```

**検証方法**:
```bash
curl -X POST https://api.kie.ai/api/v1/jobs/createTask \
  -H "Authorization: Bearer ${KIE_AI_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2-image-to-video",
    "input": {
      "prompt": "test",
      "image_urls": ["https://example.com/test.jpg"]
    }
  }'
```

期待レスポンス:
```json
{
  "job_id": "job_xxxxx",
  "status": "pending"
}
```

### 1.2 Google Drive API認証設定

**手順**:
1. Google Cloud Console → 新規プロジェクト作成
2. APIs & Services → Library → Google Drive API を有効化
3. Credentials → Create Credentials → Service Account
4. Service Account作成 → Keys → Add Key → JSON

**n8n Credentials設定**:
1. n8n UI → Credentials → Add Credential → Google Drive OAuth2 API
2. JSONファイル内容をペースト
3. Test connectionで検証

**必要な権限**:
- `https://www.googleapis.com/auth/drive.file` (ファイル作成・共有)

## 🔧 トラブルシューティング

### Issue 1: Google Drive 403 Forbidden
**原因**: Service Accountに権限不足
**解決策**:
```bash
# Google Drive Folder を Service Account と共有
# Folder ID: GOOGLE_DRIVE_FOLDER_ID
# Service Account Email: xxx@xxx.iam.gserviceaccount.com
# Permission: Editor
```

### Issue 2: kie.ai Rate Limit
**原因**: API呼び出し頻度制限
**解決策**:
```javascript
// Wait nodeの待機時間を延長
{
  "unit": "seconds",
  "amount": 60  // 30秒 → 60秒に変更
}
```

### Issue 3: ポーリングタイムアウト
**原因**: 動画生成が10分以上かかる
**解決策**:
```javascript
// IFノードにループカウンタ追加
{
  "conditions": [
    {
      "leftValue": "={{ $json.status }}",
      "rightValue": "completed",
      "operator": "equals"
    },
    {
      "leftValue": "={{ $json.loop_count }}",
      "rightValue": 20,  // 最大20回（10分）までポーリング
      "operator": "lessThan"
    }
  ]
}
```
