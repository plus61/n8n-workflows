## kie.ai API概要

### サービス概要
- **公式サイト**: https://kie.ai/
- **ドキュメント**: https://docs.kie.ai/
- **主要機能**: AI動画生成、AI画像生成、音楽生成

### 対応モデル
- **Veo 3.1** (Google): 高品質動画生成
- **Runway Gen-3 Alpha**: 動画生成・スタイル変換
- **Midjourney**: 画像生成
- **Nano Banana**: キャラクター一貫性画像生成

### 価格優位性
- **Veo 3.1**: 最も手頃な価格のVeo 3 API
- **Runway**: 競合より低価格
- **統合API**: 1つのAPIキーで複数モデル利用可能

## Veo 3.1 Video Generation API仕様

### 1. エンドポイント

**Base URL**: `https://api.kie.ai`

**Video Generation**:
```
POST /api/v1/veo/generate
```

**Status Check** (推定):
```
GET /api/v1/veo/status/{taskId}
```

### 2. 認証

**Method**: Bearer Token

**Header**:
```
Authorization: Bearer YOUR_API_KEY
```

**APIキー取得**:
1. https://kie.ai/ でアカウント登録
2. Dashboard → API Key セクション
3. "Create API key" をクリック
4. 名前を入力してキー生成
5. 生成されたキーをコピー（二度と表示されない可能性）

### 3. リクエストパラメータ

#### 必須パラメータ

| パラメータ | 型 | 説明 |
|-----------|-----|------|
| `prompt` | string | 動画生成のためのテキストプロンプト（詳細な動作・シーン・スタイル記述） |

#### オプションパラメータ

| パラメータ | 型 | デフォルト | 説明 |
|-----------|-----|------------|------|
| `imageUrls` | array | — | 画像to動画モード用の1-2個の画像URL |
| `model` | string | `veo3_fast` | `veo3` (高品質) または `veo3_fast` (高速生成) |
| `generationType` | string | 自動判定 | `TEXT_2_VIDEO`, `FIRST_AND_LAST_FRAMES_2_VIDEO`, `REFERENCE_2_VIDEO` |
| `aspectRatio` | string | `16:9` | `16:9` (横長1080P), `9:16` (縦長モバイル), または `Auto` |
| `seeds` | integer | 自動割当 | ランダムシード（10000-99999）再現性用 |
| `callBackUrl` | string | — | 完了通知用Webhook URL |
| `enableTranslation` | boolean | `true` | プロンプト自動英訳 |
| `watermark` | string | — | カスタム透かしテキスト |

### 4. 生成モード

#### TEXT_2_VIDEO
- **用途**: テキストのみから動画生成
- **imageUrls**: 不要

#### FIRST_AND_LAST_FRAMES_2_VIDEO
- **用途**: 最初と最後のフレームから動画生成
- **imageUrls**: 2個の画像URL
  - 1個目: 開始フレーム
  - 2個目: 終了フレーム

#### REFERENCE_2_VIDEO
- **用途**: 参照画像ベースの動画生成
- **imageUrls**: 1-3個の画像URL
- **動作**: 参照画像を中心に動画展開

### 5. レスポンス形式

#### 成功レスポンス (HTTP 200)
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "taskId": "veo_task_abcdef123456"
  }
}
```

#### エラーコード

| コード | 意味 | 対応方法 |
|-------|------|----------|
| 200 | 成功 | taskIdで状態確認 |
| 400 | 1080P処理中 | 1-2分待機後リトライ |
| 401 | 認証失敗 | APIキー確認 |
| 402 | クレジット不足 | チャージ必要 |
| 404 | リソース不明 | エンドポイント確認 |
| 422 | バリデーションエラー | パラメータ確認 |
| 429 | レート制限 | リクエスト頻度削減 |
| 455 | サービス利用不可 | 後でリトライ |
| 500 | サーバーエラー | kie.aiサポート連絡 |
| 501 | 生成失敗 | プロンプト修正/画像変更 |
| 505 | 機能無効 | サポート確認 |

## n8nでのHTTP Request設定

### 1. HTTP Requestノード基本設定

#### Method
```
POST
```

#### URL
```
https://api.kie.ai/api/v1/veo/generate
```

#### Authentication
```
Predefined Credential Type: Header Auth
```

または

```
Generic Credential Type: HTTP Header Auth
```

### 2. 認証設定（推奨方法）

#### Option A: Header Auth Credential（推奨）

**Credential作成**:
1. n8n UI → Credentials → Add Credential
2. Type: "Header Auth" を選択
3. Name: `kie.ai API Key`
4. Headers:
   - Name: `Authorization`
   - Value: `Bearer YOUR_API_KEY_HERE`
5. Save

**HTTP Requestノードで使用**:
- Authentication: `Header Auth`
- Credential: 上記で作成した `kie.ai API Key` を選択

#### Option B: 直接ヘッダー設定（非推奨）

**Headers**:
```json
{
  "Authorization": "Bearer {{ $env.KIE_AI_API_KEY }}"
}
```

**注意**: 環境変数 `KIE_AI_API_KEY` に実際のAPIキーを設定すること

### 3. Request Body設定

#### Body Content Type
```
JSON
```

#### Specify Body
```
Using JSON
```

#### JSON Body
```json
{
  "prompt": "={{ $json.prompt }}",
  "imageUrls": "={{ $json.imageUrls }}",
  "model": "veo3_fast",
  "aspectRatio": "16:9",
  "callBackUrl": "={{ $json.callBackUrl }}",
  "enableTranslation": true
}
```

**n8n Expression例（動的設定）**:
```javascript
{
  "prompt": "={{ $json.video_prompt || 'A beautiful sunset over mountains' }}",
  "imageUrls": "={{ $json.image_url ? [$json.image_url] : undefined }}",
  "model": "={{ $json.model || 'veo3_fast' }}",
  "aspectRatio": "={{ $json.aspect_ratio || '16:9' }}",
  "enableTranslation": true
}
```

### 4. Options設定

#### Response Format
```
JSON
```

#### Timeout
```
30000 (30秒)
```
※動画生成タスク作成のみなので短時間で完了

## 認証設定（APIキー取得と設定）

### APIキー取得手順

#### Step 1: kie.aiアカウント作成
1. https://kie.ai/ にアクセス
2. Sign Up（アカウント登録）
3. メール認証完了

#### Step 2: APIキー生成
1. ログイン後、Dashboard へ移動
2. 左メニュー → **API Key** セクション
3. **Create API key** ボタンクリック
4. Name入力（例: `n8n-wf10-production`）
5. **Create** ボタンクリック
6. 生成されたAPIキーを**コピー**（重要: 二度と表示されない可能性）

#### Step 3: APIキー形式確認
- **正しい形式**: `sk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx` （推定）
- **長さ**: 32-64文字程度（推定）
- **間違った形式**: job_id形式（`7629519cd4936fb8e9295113e081a3fc`）は動画生成タスクID

### n8nへのAPIキー設定

#### Option A: Railway環境変数（推奨 - WF10-Main用）

**Railway Dashboard経由**:
1. https://railway.app/ → プロジェクト選択
2. n8n service → Variables タブ
3. `KIE_AI_API_KEY` を検索
4. Edit → 正しいAPIキーに更新
5. **Deploy** (再デプロイ自動実行)

**n8nワークフローで参照**:
```javascript
{{ $env.KIE_AI_API_KEY }}
```

#### Option B: n8n Credential（ローカル開発用）

**Credential作成**:
1. n8n UI → Credentials
2. Add Credential → Header Auth
3. Name: `kie.ai API Key`
4. Header Name: `Authorization`
5. Header Value: `Bearer YOUR_ACTUAL_API_KEY`
6. Save

### APIキーセキュリティ

#### 保護機能
- **IP Whitelist**: 最大10個のIPアドレス制限可能
- **Safe-spend Limits**: 時間/日単位のクレジット上限設定
- **Key Rotation**: 定期的なキー再生成推奨

#### 注意事項
- ❌ **禁止**: ワークフローJSONに直接APIキーをハードコード
- ✅ **推奨**: 環境変数またはCredential経由で参照
- ✅ **推奨**: GitリポジトリにAPIキーをコミットしない

## トラブルシューティング

### よくあるエラーと対処法

#### Error 1: HTTP 401 Unauthorized
**原因**:
- APIキーが無効
- `Authorization` ヘッダーのフォーマット間違い
- `Bearer` と APIキーの間にスペースがない

**対処法**:
1. APIキー再確認（kie.ai Dashboard → API Key）
2. ヘッダー形式確認: `Bearer YOUR_API_KEY` (スペース必須)
3. 環境変数 `KIE_AI_API_KEY` の値確認
4. Railway再デプロイ（環境変数更新後）

#### Error 2: HTTP 500 "image_url File type not supported"
**原因**:
- 無効な画像URL
- Google Drive URLが間違っている
- `$json.id` が権限ID（`anyoneWithLink`）を参照

**対処法**:
1. Create Direct Link修正（このドキュメントの手順参照）
2. 画像URLフォーマット確認: `https://drive.google.com/uc?export=view&id={ACTUAL_FILE_ID}`
3. Google Drive共有設定確認（"Anyone with the link"）

#### Error 3: HTTP 402 Insufficient credits
**原因**: kie.aiクレジット不足

**対処法**:
1. kie.ai Dashboard → Billing
2. クレジットチャージ
3. Safe-spend Limits確認

#### Error 4: HTTP 422 Validation error
**原因**: リクエストパラメータ不正

**対処法**:
1. `prompt` が空でないか確認
2. `imageUrls` が配列形式か確認: `["url1", "url2"]`
3. `aspectRatio` が有効値か確認: `16:9`, `9:16`, `Auto`
4. `model` が有効値か確認: `veo3`, `veo3_fast`

#### Error 5: HTTP 429 Rate limit exceeded
**原因**: リクエスト頻度過多

**対処法**:
1. Wait時間延長（30秒 → 60秒）
2. リトライロジック実装
3. kie.aiサポートにレート制限緩和依頼
