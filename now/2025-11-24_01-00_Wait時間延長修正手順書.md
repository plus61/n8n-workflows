# WF10 Wait時間延長修正手順書

**作成日時**: 2025-11-24 01:00:19 JST
**対象ワークフロー**: WF10-Main: kie.ai Sora 2 ビデオ生成 (ID: kxKLB0EWlOhOjaOv)
**修正対象ノード**: Wait (Wait node)

---

## 🎯 修正目的

kie.ai動画生成完了を確実に検出するため、Wait時間を延長する。

---

## 📊 検証結果

### Execution #3935 分析

**動画生成時間**: 30秒（kie.ai UIで確認）
**現在のWait時間**: 5秒
**Get Statusチェック時点**: 動画生成開始前 → `data: null`

**結論**: Wait時間が短すぎて、動画生成が開始される前にGet Statusをチェックしている

---

## ✅ 推奨設定

### Wait ノードの設定変更

**現在の設定**:
```
Amount: 5
Unit: seconds
```

**推奨設定**:
```
Amount: 30
Unit: seconds
```

**理由**:
- kie.ai動画生成時間: 平均30秒（検証済み）
- 30秒待機することで、動画生成が確実に開始される
- Get Statusが `{ status: "processing" }` または `{ status: "completed" }` を返す確率が高い

## 📝 代替アプローチ（オプション）

### Option A: より長い待機時間

- **Wait時間**: 60秒
- **メリット**: 動画完成の可能性が高い（Loopが不要になる場合も）
- **デメリット**: 常に60秒待つため、短時間完成の場合は無駄

### Option B: 段階的チェック

1. **Wait 1**: 15秒
2. **Get Status 1**: 初回チェック
3. **IF**: data !== null → 次へ
4. **ELSE**: Wait 2（15秒追加）→ 再チェック

**メリット**: 柔軟
**デメリット**: ワークフロー複雑化

**推奨**: まずはシンプルに30秒固定で試す
