## 🚨 根本原因の特定

### 実行 #3944 および #3950 の共通問題

**症状**:
- Get Statusは `{ code: 200, msg: "success", data: null }` を返す
- Check Statusが常にLoop側（false分岐）に進む
- Extract Video URLとUpdate Notionノードが実行されない（12/14で停止）

**根本原因**: **Check Statusノードの条件式が間違っている**

## 📊 データ構造の正しい理解

### Get Statusノードのレスポンス構造

**動画生成中**:
```json
{
  "code": 200,
  "msg": "success",
  "data": null  // ← まだ生成開始されていない
}
```

**動画生成開始後**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "status": "processing",  // ← ここにstatusがある
    "progress": 45
  }
}
```

**動画生成完了**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "status": "completed",  // ← ここにstatusがある
    "videoUrl": "https://..."
  }
}
```

## ❌ 現在の誤った設定

### Check Statusノードの条件式（誤り）

```javascript
{
  "conditions": {
    "conditions": [
      {
        "leftValue": "={{ $json.status }}",  // ← 誤り！
        "rightValue": "completed",
        "operator": "equals"
      }
    ]
  }
}
```

**問題点**:
- `$json.status` → `undefined`（`status`フィールドはルートに存在しない）
- 正しいパス: `$json.data.status`

**結果**:
- `undefined === "completed"` → 常に `false`
- 動画生成が完了しても、永遠にLoop側に進む

---

## ✅ 正しい設定

### Check Statusノードの条件式（修正後）

```javascript
{
  "conditions": {
    "conditions": [
      {
        "leftValue": "={{ $json.data.status }}",  // ← 修正！
        "rightValue": "completed",
        "operator": "equals"
      }
    ]
  }
}
```

**変更箇所**:
- ❌ `$json.status` → ✅ `$json.data.status`
