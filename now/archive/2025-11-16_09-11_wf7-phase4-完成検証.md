#### Step 2: HTTP Request Node設定（Creatomate API呼び出し）✅
- **ノード名**: Call Creatomate API
- **タイプ**: HTTP Request Node (v4.2)
- **機能**:
  - Creatomate Render API（POST /v1/renders）への呼び出し
  - Bearer認証でAPI KEYを送信
  - RenderScript JSONをリクエストボディに設定
  - render IDを含むレスポンスを返す
- **位置**: [680, 300]

#### Step 3: Wait Node + ポーリングループ実装 ✅
6つのノードで構成されるポーリングメカニズム:

1. **Init Polling Counter** (Code Node)
   - render IDを抽出
   - カウンター初期化（pollCounter=0, maxPolls=60）
   - 位置: [900, 300]

2. **Wait 5 Seconds** (Wait Node)
   - 5秒間の待機
   - webhook ID: poll-wait-webhook
   - 位置: [1120, 300]

3. **Check Render Status** (HTTP Request Node)
   - GET /v1/renders/{renderId}でステータス取得
   - Bearer認証
   - 位置: [1340, 300]

4. **Increment Counter** (Code Node)
   - pollCounter++
   - ステータスと動画URLを保持
   - 位置: [1560, 300]

5. **Check If Succeeded** (IF Node)
   - 条件: status === "succeeded"
   - true出力: Extract Video URL（Step 4）へ
   - false出力: Check If Continue Polling へ
   - 位置: [1780, 300]

6. **Check If Continue Polling** (IF Node)
   - 条件: pollCounter <= maxPolls AND status === "rendering"
   - true出力: Wait 5 Seconds（ループ継続）
   - false出力: End（タイムアウト/失敗）
   - 位置: [1780, 480]

#### Step 4: 動画URL抽出 + Notion更新 ✅
2つのノードで構成される成功パス:

1. **Extract Video URL** (Code Node)
   - Creatomate成功レスポンスから動画URLを抽出
   - Phase1からTaskID、Titleを取得
   - Notion更新用のデータを準備
   - 出力: videoUrl, taskId, title, status="Phase4完了", completedAt
   - 位置: [2000, 200]

2. **Update Notion Hub** (Notion Node)
   - resource: databasePage
   - operation: update
   - 更新プロパティ:
     - VideoURL: 動画URLを設定
     - Status: "Phase4完了"に更新
     - CompletedAt: 完了日時を記録
   - 位置: [2220, 200]
