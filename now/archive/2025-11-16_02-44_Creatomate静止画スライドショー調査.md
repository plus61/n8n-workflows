### 最小構成例（1画像 + トランジション）

```json
{
  "output_format": "mp4",
  "width": 1080,
  "height": 1920,
  "elements": [
    {
      "type": "image",
      "source": "https://images.pexels.com/photos/7193859/pexels-photo-7193859.jpeg",
      "track": 1,
      "duration": 5,
      "animations": [
        {
          "type": "scale",
          "start_scale": "120%",
          "end_scale": "100%",
          "duration": 5,
          "easing": "cubic-in-out"
        }
      ]
    },
    {
      "type": "text",
      "text": "動画制作の時短術",
      "font_family": "Noto Sans JP",
      "track": 2,
      "duration": 5
    }
  ]
}
```

### n8n実装パターン（公式チュートリアルから）

```
1. HTTP Request (POST):
   - URL: https://api.creatomate.com/v1/renders
   - Header: Authorization: Bearer {API_KEY}
   - Body: Template JSON with modifications

2. Wait (60秒):
   - レンダリング時間確保

3. HTTP Request (GET):
   - URL: https://api.creatomate.com/v1/renders/{render_id}
   - ステータス確認

4. Switch Node:
   - status = "succeeded" → 完了
   - status = "being_processed" → Wait へループバック
   - status = "failed" → エラー通知
```

## 📝 API仕様詳細

### エンドポイント

**POST** `https://api.creatomate.com/v2/renders`

**認証**: Bearer Token

### 必須要素

```json
{
  "output_format": "mp4",
  "width": 1080,
  "height": 1920,
  "duration": 80,  // 全体の長さ（秒）
  "elements": [
    // 画像、テキスト、音声要素の配列
  ]
}
```

### サポートされる要素タイプ

1. **image**:
   - `source`: 画像URL
   - `track`: トラック番号（同一トラック = シーケンシャル再生）
   - `duration`: 表示時間（秒）
   - `animations`: アニメーション配列

2. **text**:
   - `text`: 表示テキスト
   - `font_family`: フォント名（例: "Noto Sans JP"）
   - `font_size`: フォントサイズ
   - `color`: カラーコード
   - `x`, `y`: 位置

3. **audio**:
   - `source`: 音声URL or TTS構文（例: `"tts://ja-JP:テキスト"`）
   - `duration`: 再生時間（秒）

### トランジション効果

- **type**: "slide", "fade", "wipe", "zoom" など
- **duration**: トランジション時間（1秒推奨）
- **easing**: "cubic-in-out", "linear", "ease-in" など
- **direction**: 角度（例: "180°"）

### Ken Burns エフェクト（ズーム）

```json
{
  "type": "scale",
  "start_scale": "120%",
  "end_scale": "100%",
  "duration": 5,

}
```

## ⚠️ CRITICAL UNKNOWN - Phase 0で検証必須

公式ドキュメントで**明示的に確認できなかった項目**:

### 1. 日本語テキストレンダリング

- **課題**: `font_family: "Noto Sans JP"` が機能するか
- **リスク**: 文字化けや表示崩れの可能性
- **検証方法**: Phase 0で3秒動画に日本語テキストを表示

### 2. 日本語TTS (Text-to-Speech)

- **課題**: `"source": "tts://ja-JP:動画制作の時短術を知りたいですか？"` の品質
- **リスク**: 音質が低い、日本語非対応の可能性
- **検証方法**: Phase 0で短いナレーションを生成してテスト

### 3. トランジション効果の日本語字幕への影響

- **課題**: スライドトランジション中の字幕可読性
- **リスク**: 動きが速すぎて読みにくい可能性
- **検証方法**: Phase 1で7セグメント構成をテスト

## 📦 Phase 0 検証計画（更新版）

### 検証項目

```python
# test_creatomate_minimal.py
from creatomate import Client
import os

client = Client(api_key=os.getenv("CREATOMATE_API_KEY"))

# 最小テンプレート：1枚画像 + 日本語テキスト + 日本語TTS
template = {
    "output_format": "mp4",
    "width": 1080,
    "height": 1920,
    "duration": 3,
    "elements": [
        # 1. 画像（Pexels取得済み）
        {
            "type": "image",
            "source": "https://images.pexels.com/photos/7193859/pexels-photo-7193859.jpeg",
            "track": 1,
            "duration": 3,
            "animations": [
                {
                    "type": "scale",
                    "start_scale": "120%",
                    "end_scale": "100%",
                    "duration": 3,
                    "easing": "cubic-in-out"
                }
            ]
        },

        # 2. 日本語テキスト（CRITICAL検証）
        {
            "type": "text",
            "text": "動画制作の時短術",
            "font_family": "Noto Sans JP",
            "font_size": 60,
            "color": "#FFFFFF",
            "y": "50%",
            "track": 2,
            "duration": 3
        },

        # 3. 日本語TTS（CRITICAL検証）
        {
            "type": "audio",
            "source": "tts://ja-JP:動画制作の時短術を知りたいですか？",
            "track": 3,
            "duration": 3
        }
    ]
}

# レンダリング実行
render = client.renders.create(template)

# 完了待機（ポーリング）
import time
while render.status != "succeeded":
    if render.status == "failed":
        print(f"❌ レンダリング失敗: {render.error}")
        break
    time.sleep(5)
    render = client.renders.get(render.id)
    print(f"⏳ Status: {render.status}")

print(f"✅ 完成！ {render.url}")
```

### Go/No-Go 判定基準

| 項目 | 合格基準 | 不合格時の対応 |
|------|---------|--------------|
| 日本語テキスト | 正常表示、文字化けなし | 画像に焼き込み or 別サービス検討 |
| 日本語TTS | 聞き取れる品質（主観評価70点以上） | ElevenLabs等の外部TTS使用 |
| レンダリング時間 | 3秒動画が60秒以内に完成 | 問題なし（スペック範囲内） |
| API安定性 | 3回連続成功 | リトライロジック実装 |
