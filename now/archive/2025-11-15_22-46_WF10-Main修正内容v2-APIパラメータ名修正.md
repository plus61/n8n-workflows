## 🐛 発見された問題（実行2422のAPIエラーから判明）

### APIエラーレスポンス
```json
{
  "error": "Unexpected status code: 422",
  "payload": {
    "detail": [
      {
        "loc": ["body", "prompt"],
        "msg": "field required"
      },
      {
        "loc": ["body", "image_url"],
        "msg": "field required"
      },
      {
        "loc": ["body", "duration"],
        "msg": "unexpected value; permitted: '5', '10'"
      }
    ]
  },
  "status": "ERROR"
}
```

### 問題点の詳細

1. **パラメータ名の誤り**（v1の問題）:
   - ❌ `prompt_image` → ✅ `image_url`
   - ❌ `prompt_text` → ✅ `prompt`

2. **duration値の誤り**（v1の問題）:
   - ❌ `duration: 20` → ✅ `duration: 5 or 10`（Turboは5または10秒のみサポート）

## 📊 fal.ai Runway Gen-3 Turbo API 正式パラメータ仕様

**実行2422のエラーメッセージから確定した仕様**:

| パラメータ名 | 型 | 必須 | 説明 | 許可値 |
|-------------|-----|------|------|--------|
| `image_url` | string | ✅ Yes | 入力画像のURL | 任意のHTTPS URL |
| `prompt` | string | ✅ Yes | テキストプロンプト | 512文字以下 |
| `duration` | integer | ✅ Yes | 動画の長さ（秒） | **5または10のみ** |
| `ratio` | string | No | アスペクト比 | "16:9"（デフォルト）または"9:16" |

**重要な制約**:
- ⚠️ **Turboモデルは5秒または10秒の動画のみ生成可能**
- ⚠️ 20秒動画が必要な場合は、Turboでない通常のGen-3モデルを使用する必要がある
