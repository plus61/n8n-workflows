## 🚀 セットアップ手順（3ステップ）

### ステップ1: Cloudinary認証情報を取得

1. [Cloudinaryダッシュボード](https://console.cloudinary.com/)にログイン
2. **Settings > Account** で `CLOUDINARY_CLOUD_NAME` を確認
3. **Settings > API Keys** で `CLOUDINARY_API_KEY` と `CLOUDINARY_API_SECRET` を確認

### ステップ2: Railway環境変数を設定

**オプションA: 自動セットアップスクリプト使用（推奨）**

```bash
cd /Users/yuichiroooosuger/Desktop/n8n-workflows/now
./2025-11-15_01-04_setup-cloudinary-env.sh
```

プロンプトに従ってCloudinary認証情報を入力してください。

**オプションB: 手動設定（Railway Dashboard使用）**

1. [Railway Dashboard](https://railway.app)を開く
2. `fastapi-server` サービスを選択
3. **Variables** タブをクリック
4. 以下の3つの環境変数を追加：
   ```
   CLOUDINARY_CLOUD_NAME=<your-cloud-name>
   CLOUDINARY_API_KEY=<your-api-key>
   CLOUDINARY_API_SECRET=<your-api-secret>
   ```

**オプションC: Railway CLI手動コマンド**

```bash
railway variables \
  --service fastapi-server \
  --set "CLOUDINARY_CLOUD_NAME=<your-cloud-name>" \
  --set "CLOUDINARY_API_KEY=<your-api-key>" \
  --set "CLOUDINARY_API_SECRET=<your-api-secret>"
```

### ステップ3: サービス再デプロイ確認

環境変数を追加すると、Railwayが自動的に再デプロイを開始します。

**再デプロイ状態の確認**:
```bash
railway logs --service fastapi-server
```

## ⚠️ トラブルシューティング

### 問題1: Cloudinary認証エラー

**エラーメッセージ**:
```
Cloudinary credentials not configured. Set CLOUDINARY_CLOUD_NAME,
CLOUDINARY_API_KEY, and CLOUDINARY_API_SECRET environment variables.
```

**対処方法**:
1. 環境変数が正しく設定されているか確認：
   ```bash
   railway variables --service fastapi-server | grep CLOUDINARY
   ```
2. Railway サービスが再デプロイされているか確認
3. 環境変数の値に余分なスペースや改行がないか確認

### 問題2: Cloudinaryアップロード失敗

**動作**:
- Cloudinaryアップロードが失敗しても、base64形式のレスポンスは返される
- `image_url` フィールドは `null` になる

**ログ出力**:
```
⚠️ Cloudinary upload failed: <error message>
```

**対処方法**:
1. Cloudinary APIの制限に達していないか確認
2. ネットワーク接続を確認
3. Cloudinaryダッシュボードでストレージ上限を確認
4. Railway logsでエラー詳細を確認：
   ```bash
   railway logs --service fastapi-server | grep -i cloudinary
   ```

### 問題3: テストスクリプトが失敗する

**エラー**: `image_url: null` が返される

**対処方法**:
1. 環境変数設定を再確認（ステップ2に戻る）
2. Railway サービスの再デプロイを待つ（2-5分）
3. 手動でサービスを再デプロイ：
   ```bash
   railway redeploy --service fastapi-server
   ```

```python
def upload_image_to_cloudinary(img: Image.Image, section: str, script_id: str) -> str:
    """
    Upload PIL Image to Cloudinary and return public URL

    Args:
        img: PIL Image object to upload
        section: Section name (hook, intro, point1, etc.)
        script_id: Notion script ID for folder organization

    Returns:
        str: Cloudinary public URL (https://res.cloudinary.com/...)

    Raises:
        RuntimeError: If Cloudinary credentials not configured
        Exception: If upload fails
    """
```
