### Task 2: WF10-Main Workflow作成
**工数**: 1.5🍅（90分）

**設定**:
- Execute Workflow: `On clicking 'Test workflow'`
- 入力データ（ハードコード）:
  ```json
  {
    "台本本文": "A professional presenter explaining AI technology in a modern office",
    "画像素材URL": ["https://storage.googleapis.com/your-test-image.jpg"],
    "Notion_Page_ID": "test-page-001"
  }
  ```

**Phase 1での拡張**:
- Notion Database Triggerに変更
- 台本データベースから自動取得

#### Node 2: HTTP Request - Runway Gen-3 API
**タイプ**: HTTP Request
**設定**:
```yaml
Method: POST
URL: https://queue.fal.run/fal-ai/runway-gen3/turbo/image-to-video
Authentication: fal-api-auth (Predefined Credentials)
Headers:
  Content-Type: application/json
Body (JSON):
  {
    "prompt_image": "={{ $json.画像素材URL[0] }}",
    "prompt_text": "={{ $json.台本本文 }}",
    "duration": 20,
    "ratio": "16:9",
    "webhook_url": "https://n8n-python-production-344b.up.railway.app/webhook/wf10-runway-webhook"
  }
Options:
  - Response Format: JSON
  - Timeout: 30000 (30秒)
```

**重要パラメータ**:
- `duration: 20` - 20秒動画（Phase 0検証対象）
- `webhook_url` - WF10-Webhook Sub-workflowのURL
- `guidance_scale` - デフォルト値使用（後で最適化）

## 🔧 2. 技術仕様詳細

### 2.1 fal.ai Queue System API仕様

#### リクエスト形式
```http
POST https://queue.fal.run/fal-ai/runway-gen3/turbo/image-to-video
Authorization: Key YOUR_API_KEY
Content-Type: application/json

{
  "prompt_image": "https://example.com/image.jpg",
  "prompt_text": "Video description",
  "duration": 5 | 10 | 20,
  "ratio": "16:9" | "9:16" | "1:1",
  "guidance_scale": 1.0-10.0,  // デフォルト: 3.0
  "webhook_url": "https://your-webhook.com/endpoint"
}
```

#### レスポンス形式（即時）
```json
{
  "request_id": "req_a1b2c3d4e5f6",
  "status": "IN_QUEUE"
}
```

#### Webhook Payload（完了時）
```json
{
  "request_id": "req_a1b2c3d4e5f6",
  "status": "completed",
  "video": {
    "url": "https://fal.media/files/xxx/video.mp4",
    "content_type": "video/mp4",
    "file_name": "video.mp4",
    "file_size": 12582912,
    "width": 1280,
    "height": 720,
    "duration": 20.0
  },
  "timings": {
    "queued_at": "2025-11-15T08:00:00Z",
    "started_at": "2025-11-15T08:00:05Z",
    "completed_at": "2025-11-15T08:02:30Z"
  }
}
```

### 2.2 エラーハンドリング仕様

#### エラーケース1: Webhook未到達
**検出**: WF10-Main実行後5分経過でWebhook未受信
**対応**:
1. fal.ai Status Check API呼び出し
   ```http
   GET https://queue.fal.run/fal-ai/runway-gen3/turbo/image-to-video/requests/{request_id}/status
   Authorization: Key YOUR_API_KEY
   ```
2. ステータス確認:
   - `completed` → 手動Webhook Trigger実行
   - `failed` → エラー通知、Notion更新
   - `IN_QUEUE` / `IN_PROGRESS` → 再度3分待機

#### エラーケース2: 動画生成失敗
**Webhook Payload**:
```json
{
  "request_id": "req_xxx",
  "status": "failed",
  "error": {
    "message": "Invalid prompt image format",
    "code": "INVALID_INPUT"
  }
}
```

**対応**:
- Notion更新: ステータス = "失敗"
- エラーメッセージ記録
- Slack通知（Phase 1）

#### エラーケース3: API Rate Limit
**レスポンス**:
```json
{
  "error": "Rate limit exceeded",
  "retry_after": 60
}
```

**対応**:
- n8n Wait Node（60秒）
- 自動リトライ（最大3回）
