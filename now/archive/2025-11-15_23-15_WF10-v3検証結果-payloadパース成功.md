## 📚 技術的知見

### fal.ai Webhook Payload構造
```json
{
  "status": "completed",
  "request_id": "uuid",
  "payload": {  // ⚠️ 重要：videoはpayloadの下にネスト
    "video": {
      "url": "https://v3.fal.media/files/...",
      "duration": 10,
      "width": 1920,
      "height": 1080
    }
  }
}
```

### n8n Expression正しいパス
```javascript
// ❌ 誤り（v2以前）
"={{ $json.body.video.url }}"

// ✅ 正しい（v3）
"={{ $json.body.payload.video.url }}"
```

### テストペイロード注意点
curlでwebhookテストする際は、`payload`ラッパーを含める必要がある：
```json
{
  "status": "completed",
  "payload": {  // ← これを忘れずに
    "video": { "url": "..." }
  }
}
```
