# WF10 Notionボタン設定手順書

**作成日時**: 2025-11-23 02:03:50 JST

## 概要

WF10ワークフロー（kie.ai Sora 2動画生成）をNotionから手動でトリガーするためのボタン設定手順書です。

## 前提条件

- WF10ワークフローが既にn8nにデプロイ済み
- Webhookエンドポイント: `https://n8n-python-production-344b.up.railway.app/webhook/wf10-notion-trigger`
- Notionデータベース: WF10 Video Generation Tasks (ID: `2b368d5c29868175957ff890b8b27e93`)

## 設定手順

### 方法1: Embedブロックでボタンを作成

#### Step 1: NotionページにEmbedブロックを追加

1. Notionデータベースの任意のページを開く
2. `/embed` と入力してEmbedブロックを作成
3. 以下のHTMLコードを貼り付け

#### Step 2: HTMLコード

```html
<!DOCTYPE html>
<html>
<head>

  <style>
    body {

  <div class="button-container">

      🎬 動画生成開始
    </button>
    <div id="status" class="status-message"></div>
  </div>

  <script>
    async function triggerWorkflow() {
      const statusEl = document.getElementById('status');
      statusEl.textContent = '処理中...';
      statusEl.className = 'status-message';

      try {
        // NotionページURLからページIDを抽出
        // 例: https://www.notion.so/My-Page-123abc456def → 123abc456def
        const pageUrl = window.location.href;
        const pageIdMatch = pageUrl.match(/([a-f0-9]{32})/);

        if (!pageIdMatch) {
          throw new Error('ページIDを取得できませんでした');
        }

        const pageId = pageIdMatch[1];

        // Webhook呼び出し
        const response = await fetch('https://n8n-python-production-344b.up.railway.app/webhook/wf10-notion-trigger', {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({
            page_id: pageId
          })
        });

        if (!response.ok) {
          throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }

        const result = await response.json();
        statusEl.textContent = '✅ 動画生成を開始しました！';
        statusEl.className = 'status-message status-success';

        console.log('Workflow triggered:', result);

      } catch (error) {
        statusEl.textContent = `❌ エラー: ${error.message}`;
        statusEl.className = 'status-message status-error';
        console.error('Workflow trigger failed:', error);
      }
    }
  </script>
</body>
</html>
```

#### Step 3: Embedブロックの設定

- Embedブロックに上記HTMLコードをData URLとして埋め込む
- または、HTMLファイルをホスティングしてそのURLを指定

### 方法2: cURLコマンドで手動実行（開発・テスト用）

#### ページIDの取得方法

NotionページのURL末尾から32文字の英数字を取得:
```
例: https://www.notion.so/My-Page-abc123def456...
→ ページID: abc123def456...（ハイフンなし）
```

#### cURLコマンド例

```bash
# POSTリクエスト（JSON Body）
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"page_id": "YOUR_PAGE_ID_HERE"}' \
  https://n8n-python-production-344b.up.railway.app/webhook/wf10-notion-trigger

# GETリクエスト（Query Parameter）
curl "https://n8n-python-production-344b.up.railway.app/webhook/wf10-notion-trigger?page_id=YOUR_PAGE_ID_HERE"
```

## ワークフロー実行フロー

1. **ボタンクリック** → Webhook POST呼び出し
2. **Webhook Trigger** → リクエスト受信
3. **Extract Page ID** → `body.page_id` または `query.page_id` を抽出
4. **Get Notion Page** → NotionからページデータとImage_URLを取得
5. **Download Image** → 画像をダウンロード
6. **Upload to Google Drive** → Google Driveにアップロード
7. **Share File** → 公開共有設定
8. **Create Direct Link** → ダイレクトリンク生成
9. **Create Video Task** → kie.ai Sora 2 API呼び出し
10. **Wait** → 30秒待機
11. **Get Status** → ステータス確認
12. **Check Status** → 完了判定（未完了ならLoop）
13. **Extract Video URL** → 動画URL抽出
14. **Update Notion** → NotionページにVideo_URLとStatusを更新

## トラブルシューティング

### エラー: "ページIDを取得できませんでした"

- NotionページのURLが正しい形式か確認
- URLに32文字の英数字が含まれているか確認

### エラー: "HTTP 404"

- Webhookエンドポイントが正しいか確認
- n8nワークフローがアクティブか確認

### エラー: "HTTP 500"

- n8nワークフローのノード設定を確認
- Notion API認証情報が有効か確認
