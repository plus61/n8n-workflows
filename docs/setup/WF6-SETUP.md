## 5. トラブルシューティング

### 5.1 Notion API エラー

**症状**: 401 Unauthorized

**対処法**:
- NOTION_API_KEY が正しいか確認
- データベースにintegrationが追加されているか確認
- データベースIDが正しいか確認

### 5.2 OpenAI API エラー

**症状**: 429 Rate Limit Exceeded

**対処法**:
- OpenAI API使用量を確認
- レート制限内に収まるようスケジュール調整
- tier 1の場合: 3 RPM, 200 RPD

**症状**: 400 Bad Request

**対処法**:
- プロンプトが長すぎないか確認
- temperatureやmax_tokensパラメータを確認

### 5.3 Notion登録エラー

**症状**: 400 Bad Request (Notion API)

**対処法**:
- Database IDが正しいか確認
- プロパティ名が記事管理DBと一致しているか確認
- Description フィールドが2000文字以内に収まっているか確認
- NOTION_API_KEY が正しく設定されているか確認

**症状**: 記事本文が2000文字で切れている

**対処法**:
- これはNotion API制限（rich_text: 2000文字まで）
- 完全な本文はNotionページ内のコンテンツブロックに保存（将来対応）
- 現在: Descriptionプレビュー（2000文字）+ note.comへの手動コピーで回避

### 5.4 Slack通知エラー

**症状**: 404 Not Found

**対処法**:
- Webhook URLが正しいか確認
- Webhookが無効化されていないか確認
- Slackアプリの設定を確認

### 5.5 一般的なn8nエラー

**症状**: ノード間の接続エラー

**対処法**:
- 各ノードが正しく接続されているか確認
- 前のノードの出力形式が期待通りか確認

**症状**: 環境変数が読み込まれない

**対処法**:
- n8nを再起動
- 環境変数の名前が正しいか確認（大文字小文字区別）
- Docker環境の場合: `docker-compose restart`

### 5.6 WF5 トピック作成サイレント失敗 🚨 CRITICAL

**症状**:
- WF6実行時に「トピックマスタにアクティブなトピックがありません」エラー
- WF5は成功ステータスだがNotion DBにトピックが書き込まれていない
- WF5実行ログで "Loop - トピック登録" ノードがmain[0]を実行せずmain[1]に直接移行

**根本原因**:
WF5の "Notion - トピックマスタ更新" ノードで、HTTP Request Node v4のjsonBody式構文エラーにより、Loopノードが即座に完了ポート (main[1]) に移行し、Notion書き込み処理 (main[0]) が完全にスキップされた。

**詳細な原因分析**:

1. **誤った式構文** (修正前):
```javascript
// ❌ INCORRECT - string値にJSON.stringify()を使用
"content": " + JSON.stringify($json.topic) + "

// 生成されるJSON (無効):
{
  "properties": {
    "Topic Name": {
      "title": [{
        "text": {
          "content": ""子供と訪れるべきAI推薦スポットガイド""  // ← エスケープされた二重引用符
        }
      }]
    }
  }
}
```

2. **Loop動作への影響**:
- jsonBodyの構文エラーによりNotionノード実行が失敗
- Loopノードがエラーハンドリングとして完了ポート (main[1]) に移行
- 5つのトピックすべてがNotion DBに書き込まれず
- ワークフロー全体としては "success" ステータス (Slack通知が成功したため)

3. **検出が困難だった理由**:
- ワークフロー実行ステータスが "success" と表示
- エラーログが明示的に記録されない（サイレント失敗）
- Loopの完了ポート実行は正常な動作として記録される

**正しい式構文** (修正後):
```javascript
// ✅ CORRECT - string値は直接連結
"content": " + $json.topic + "

// 生成されるJSON (有効):
{
  "properties": {
    "Topic Name": {
      "title": [{
        "text": {
          "content": "子供と訪れるべきAI推薦スポットガイド"  // ← クリーンな文字列
        }
      }]
    }
  }
}
```

**n8n HTTP Request Node v4 式構文ルール**:

| データ型 | 正しい構文 | 誤った構文 | 理由 |
|---------|-----------|-----------|------|
| **String** | `" + $json.stringField + "` | `" + JSON.stringify($json.stringField) + "` | JSON.stringify()は二重引用符をエスケープ |
| **Number** | `" + $json.numberField + "` | `"\"field\": \" + $json.numberField + \"\""` | JSONで数値に引用符は不要 |
| **Array/Object** | `" + JSON.stringify($json.arrayField) + "` | `" + $json.arrayField + "` | 配列/オブジェクトはJSON.stringify必須 |
| **ISO Date** | `" + JSON.stringify(new Date().toISOString()) + "` | `" + new Date().toISOString() + "` | 文字列として扱う場合は引用符が必要 |
