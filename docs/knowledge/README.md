## 🎯 使い方

### 新規ワークフロー構築時

1. **設計フェーズ**:
   - チェックリストの「設計フェーズ」を確認
   - データフローを明確化

2. **実装フェーズ**:
   - HTTP Request Node v4設定ルールを参照
   - n8n式構文のベストプラクティスを適用
   - チェックリストの「実装フェーズ」を順次確認

3. **テストフェーズ**:
   - テストとデバッグアプローチに従う
   - 段階的テスト戦略を実行

4. **デバッグフェーズ**:
   - エラーパターンと対処法を参照
   - 実行ログの詳細分析手法を適用

### 既存ワークフロー修正時

1. **更新前**:
   - ワークフロー更新戦略を確認
   - 部分更新vs完全更新を判断
   - バージョンIDを記録

2. **更新実行**:
   - チェックリストの「ワークフロー更新時」を確認
   - 必須パラメータの保持を確認

3. **テスト**:
   - 即座にテスト実行
   - 成功するまで修正-テストサイクル

### エラー発生時

1. **エラータイプ特定**:
   - エラーパターンと対処法テーブルを参照
   - 症状から原因を特定

2. **対処法適用**:
   - 該当セクションの詳細ガイドを参照
   - デバッグ手法を実践

3. **再発防止**:
   - 修正内容をドキュメント化
   - チェックリストに追加
