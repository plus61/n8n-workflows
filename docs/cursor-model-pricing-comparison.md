## 💡 AUTOモードの特徴

### 料金体系（2025年6月以降）

```
入力トークン:      $1.25 / 100万トークン
出力トークン:      $6.00 / 100万トークン
キャッシュ済み:    $0.25 / 100万トークン（80%割引）
```

### 仕組み

- Cursorがタスクに最適な**プレミアムモデル**を自動選択
- 複雑なタスク→高品質モデル、シンプルなタスク→高速モデル
- 統一された料金体系で予測しやすい

### 使用シーン

✅ **推奨する場合**:
- タスクに最適なモデルを自動選択してほしい
- コストとパフォーマンスのバランスを重視
- 様々なタスクを扱う（コード、テキスト、分析など）
- モデル選択を意識したくない

⚠️ **注意点**:
- 個人プランでは無制限利用可能
- チームプランでは他のプレミアムモデルと同様の料金が適用
- タスクの種類によって使用されるモデルが変わる（自動選択のため）

## ⚠️ 注意事項

1. **料金は変動する可能性があります**
   - 最新の料金は各プロバイダーの公式サイトで確認してください
   - Cursor内のダッシュボードで使用量を監視してください

2. **プランごとの使用量制限**
   - Pro: $20分の使用量
   - Pro Plus: $70分の使用量
   - Ultra: $400分の使用量

3. **超過時の対応**
   - 含まれる使用量を超えると、原価で追加購入可能
   - 上位プランへのアップグレードも選択可能

4. **MCPツール使用時**
   - MCPツール（n8n-mcp等）を使用する場合は、脳アイコン付きモデルを選択してください
   - ツール使用時は追加のトークンが消費される場合があります
