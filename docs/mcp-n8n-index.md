## 🚀 使用シナリオ別ガイド

### シナリオ1: 初めてMCPを使用する

1. [クイックリファレンス](./mcp-n8n-quick-reference.md) の「30秒で動作確認」を実行
2. [動作状態ドキュメント](./mcp-n8n-working-state-documentation.md) の「設定ファイル構成」を確認
3. `.mcp/config.json.template` をコピーして設定

### シナリオ2: MCPが動作しない

1. [クイックリファレンス](./mcp-n8n-quick-reference.md) の「よくある問題と即座の解決策」を確認
2. [トラブルシューティング完全ガイド](./troubleshooting-n8n-mcp-comprehensive-guide.md) で詳細を確認
3. [動作確認ログ](./mcp-n8n-verification-log.md) に問題を記録

### シナリオ3: 定期的な動作確認

1. [動作確認ログ](./mcp-n8n-verification-log.md) の「定期的な動作確認」を参照
2. 推奨頻度に従って確認を実行
3. 結果をログに記録

### シナリオ4: 再現性を高めたい

1. [動作状態ドキュメント](./mcp-n8n-working-state-documentation.md) の「再現性を高めるためのチェックリスト」を確認
2. すべての項目をチェック
3. 設定ファイルと環境変数を確認

## 📋 チェックリスト

### 初回セットアップ

- [ ] [クイックリファレンス](./mcp-n8n-quick-reference.md) を読む
- [ ] `.mcp/config.json.template` をコピーして設定
- [ ] 環境変数を設定
- [ ] ヘルスチェックを実行
- [ ] [動作状態ドキュメント](./mcp-n8n-working-state-documentation.md) を確認

### 問題発生時

- [ ] [クイックリファレンス](./mcp-n8n-quick-reference.md) の「よくある問題」を確認
- [ ] [トラブルシューティング完全ガイド](./troubleshooting-n8n-mcp-comprehensive-guide.md) で詳細を確認
- [ ] [動作確認ログ](./mcp-n8n-verification-log.md) に問題を記録
- [ ] 解決策を実施
- [ ] 結果をログに記録

### 定期的なメンテナンス

- [ ] [動作確認ログ](./mcp-n8n-verification-log.md) の推奨頻度に従って確認
- [ ] ヘルスチェックを実行
- [ ] 結果をログに記録
- [ ] 問題があればトラブルシューティングガイドを参照
